## 一、能力映射与学习原则

### 1.1 已有能力 → 新岗位映射

| 已有能力（[A09] 等） | 对应新方向 | 需补充 |
|----------------------|------------|--------|
| 音频预处理、声学特征 | 非文本数据的特征与建模思维 | Token、文本 Embedding、文档分块 |
| PyTorch、训练循环 | 理解 loss、过拟合、验证集 | 以大模型**推理**为主，SFT 为选修 |
| 数据集与标注、评测指标 | RAG / Agent 评测集建设 | 幻觉率、引用准确率、工具成功率 |
| 比赛式 PoC 交付 | 演示与答辩 | 工程化：日志、权限、版本、部署 |
| Python、数学 | 直接复用 | 不重复系统学语法与数学课本 |

### 1.2 学习原则

1. **理论**：广而浅的 CS + ML 底子 + LLM 应用理论；数学保持「能读懂公式与论文摘要」。  
2. **实践**：以 **FastAPI + RAG + LangGraph Agent + 评测** 为主线，每个知识点对应可运行代码。  
3. **双轨**：轨道 A 跟海颐业务与对接；轨道 B 按 Agent 岗 JD 做通用 Demo（建议业余 70% 轨道 B，入职后按项目调整）。  
4. **不重复造轮子**：框架用 LangChain 组件 + **LangGraph** 编排；向量库选定一种深入。
